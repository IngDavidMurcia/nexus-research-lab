# 🚀 NEXUS Research Lab - Quick Start Guide

Welcome to the NEXUS Research Lab. This guide will help you set up and begin using the architecture in minutes.

## 📥 1. Setup the Environment

The NEXUS architecture relies on a local folder structure to simulate a multi-agent environment using your preferred Large Language Model (e.g., ChatGPT, Claude, Gemini).

1. Clone or download the repository to your local machine.
2. Locate the `DISTRIBUTION/COMPILED` folder. This is your working directory.
3. Open your preferred LLM interface (e.g., ChatGPT web interface).

## 🧠 2. Initialize the NEXUS Director

The Director is the core orchestrator of the system. It manages state, tracks progress, and instructs you on when to call Specialists.

1. Open a **new chat window** in your LLM.
2. Copy the entire contents of the `DISTRIBUTION/COMPILED/Nexus_Director.md` file.
3. Paste it into the chat and send the message.
4. The Director will acknowledge initialization and ask you for your research project details.
5. **Keep this window open.** This is your primary orchestration hub.

## 👥 3. Call Specialists On-Demand

As your project progresses, the Director will instruct you to consult specific Specialists (e.g., the Scientific Writer, the Data Analyst).

1. When instructed, open a **separate, new chat window** in your LLM.
2. Navigate to `DISTRIBUTION/COMPILED/SPECIALISTS/` in your local folder.
3. Open the markdown file for the requested Specialist (e.g., `Scientific_Writer.md`) and copy its contents.
4. Paste it into the new chat window.
5. The Specialist is now active in that window. You can relay instructions and data from the Director to the Specialist, and vice-versa.

## 🔄 4. Maintain the "YAML Snapshot"

To ensure all windows are synchronized, the Director maintains a "YAML Snapshot" representing the current state of the project.

- **Always** copy the latest YAML Snapshot generated by the Director and provide it to a Specialist when asking them to perform a task.
- This ensures the Specialist has the full context of the project without needing the entire conversation history.

**Happy Researching!** For more advanced workflows, refer to the full documentation in the repository root.
