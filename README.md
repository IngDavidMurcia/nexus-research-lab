# NEXUS Research Lab

Version: 1.0.0

NEXUS Research Lab is a modular multi-agent framework for scientific research.

## Architecture

- NEXUS Director
- Research Architect
- Scientific Writer
- Scientific Reviewer
- Publication Specialist
- Research Integrity Auditor

See `01_CORE/NEXUS_CORE.md`.
