# Instructions

This template SHALL be used to assemble the complete submission package for any scientific work leaving the NEXUS Research Lab ecosystem.

The package SHALL consolidate every validated document, required metadata, supplementary material and institutional approval into a single submission-ready record.

No submission SHALL occur without a completed Submission Package.
